Privacy Policy

FS User Stories is local-first. Your project data belongs on your computer.

No data collection by FS User Stories

FS User Stories does not operate accounts, analytics, advertising, telemetry, or a cloud service. We do not receive, sell, rent, or share your project data.

Data stored locally

Projects, profiles, user stories, notes, acceptance criteria, and managed attachments are stored locally on your Mac. You control them and can remove them by deleting a project or uninstalling the app.

Optional Git synchronization

If you choose to synchronize a project, FS User Stories sends the project content you selected to the Git remote you configure, such as GitHub, GitLab, or another provider. That provider’s privacy policy applies to its service. Authentication credentials remain in your system Keychain or Git configuration; they are not sent to FS User Stories.

Optional local MCP server

While the app is running, it can expose a loopback-only MCP endpoint for an AI client that you choose. The endpoint is available only on your Mac. Any data an AI client accesses or sends is governed by that client and its provider, not by FS User Stories.

Apple and the App Store

When you download or purchase the app through Apple, Apple may process information under its own privacy policy. FS User Stories does not receive App Store purchase information or Apple diagnostics.

Questions

For questions about this policy, open an issue in the FS User Stories source repository.
